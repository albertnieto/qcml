

# Utilidades de Computación Cuántica para Python

[![DOI](https://zenodo.org/badge/724659579.svg)](https://zenodo.org/doi/10.5281/zenodo.13632281)

Esta biblioteca está dedicada a la computación cuántica, e incluye implementaciones de puertas, algoritmos y utilidades. Este repositorio sirve como recopilación de las tareas y utilidades desarrolladas para el programa de Máster en Computación Cuántica de la UNIR. Incluye documentos de tareas educativas y un conjunto de cuadernos Jupyter con fines de aprendizaje.

## Descripción general

Esta biblioteca está diseñada para proporcionar a los desarrolladores un conjunto completo de herramientas y funcionalidades para la computación cuántica. Incluye módulos para implementaciones de puertas, manejo de diversas notaciones cuánticas, gestión de estados cuánticos, utilidades para operaciones cuánticas, así como documentos de tareas educativas y cuadernos Jupyter.

Los desarrolladores interesados en la computación cuántica pueden utilizarla para explorar algoritmos cuánticos, experimentar con implementaciones de puertas, manipular estados cuánticos y aprovechar utilidades para mejorar su comprensión y desarrollo en el ámbito de la computación cuántica.

## Contribuciones
